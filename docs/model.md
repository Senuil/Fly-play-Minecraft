# 模型與可解釋範圍

使用 mV、ms 單位，狀態為膜電位 v、突觸驅動 g：

\[
\frac{dv}{dt}=\frac{-52-v+g}{20},\qquad \frac{dg}{dt}=-\frac{g}{5}.
\]

閾值 v > −45 mV，發放後 v=−52、g=0，不應期 2.2 ms。
突觸延遲 1.8 ms；上游帶符號連線數乘 0.275 mV 注入 g。
矩陣方向是 `W[post,pre]`，不應期內凍結 v、g 的微分更新。
各連線延遲事件仍可在不應期內累積於 g。採 0.1 ms 顯式 Euler 積分。

輸入群每步按 `1-exp(-rate*dt)` 產生 Bernoulli 事件，事件向 v 注入 68.75 mV。
這個方式近似 Poisson，無法在同一神經元同一步表達多個輸入事件。
刺激率範圍上限為 500 Hz，controller 實際使用 0–180 Hz。

這些常數與方程參考 Shiu 模型，但有明確差異：

- 上游使用 Brian2 線性積分，本版為 Euler。
- 上游對受刺激神經元可取消不應期，本版所有神經元保留 2.2 ms 不應期。
- 本版有 50 ms 讀出窗、指數平滑與人工輸出解碼，上游實驗不是 Minecraft 控制器。
- 本次沒有逐 spike / 統計對照 Brian2，不宣稱神經生理預測準確率。

來源：[上游 model.py](https://github.com/philshiu/Drosophila_brain_model/blob/main/model.py)。
後續若以生理研究為目標，應先對照原始實作，再比較各後端。

`fixtures/probe` 保留真實六個神經元及其誘導子圖，root ID 是字串，避免 JS 浮點精度損失。
它是連線測試探針，不是天然反射迴路。被切出的外部輸入全部不存在，不能把子圖行為視為活體行為。
強連線挑選也有選擇偏差，需在後續換成有解剖來源支持的完整路徑。

可用的最低因果驗證：相同刺激下把 W 歸零、重設狀態後，前進和轉向消失。
這證明 action 取決於神經傳播，不證明模型與果蠅真實行為等價。
